# Presentaties

## Acute poort en Hotfloor – eenvoudige versie

`Acute_poort_en_Hotfloor_eenvoudig.pptx` is de vereenvoudigde (101) versie van de
presentatie *Integraal capaciteitsmanagement – Acute poort en Hotfloor*. Zestien dia's,
één boodschap per dia, met de details in de sprekersnotities en de bijlage.

Opnieuw genereren:

```bash
npm install pptxgenjs sharp react react-dom react-icons
node presentaties/build_acute_poort_hotfloor.js presentaties/Acute_poort_en_Hotfloor_eenvoudig.pptx
```
